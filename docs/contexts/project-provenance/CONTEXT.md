# Project Provenance

This context defines the language used to describe RC MetaStudio's relationship to the original OpenMeta[Analyst] project, its maintainership, licensing posture, and attribution boundaries.

## Language

**RC MetaStudio**:
The maintained desktop evidence-synthesis application derived from OpenMeta[Analyst] and independently maintained by Ali Salman and RC MetaStudio contributors.
_Avoid_: OpenMeta[Analyst] Community, OpenMetaAnalyst, Open Meta-Analyst

**Research Consultancy (RC)**:
The publisher and organization identity for RC MetaStudio.
_Avoid_: Brown University, Tufts Medical Center, CEBM/CEBM@Brown

**Original OpenMeta[Analyst] Project**:
The abandoned GPL-2.0-or-later project originally created and maintained by Byron C. Wallace, George Dietz, and Paul Trow through Brown University, Tufts Medical Center, and CEBM/CEBM@Brown.
_Avoid_: Current upstream, active maintainer project

**Derived Maintained File**:
A file that descends from the Original OpenMeta[Analyst] Project and has been rewritten, edited, ported, or otherwise modified for RC MetaStudio.
_Avoid_: Untouched legacy file, purely new file

**New Maintained File**:
A file created independently for RC MetaStudio without copied expression from the Original OpenMeta[Analyst] Project.
_Avoid_: Derived file, legacy file

**RC MetaStudio Modification Notice**:
The copyright and license notice that identifies Ali Salman and RC MetaStudio contributors as maintainers of modifications while preserving applicable original copyright notices for derived portions.
_Avoid_: Replacement copyright, ownership rewrite

**Affiliation Disclaimer**:
The statement that RC MetaStudio is not affiliated with, endorsed by, sponsored by, supported by, or maintained by Brown University, Tufts Medical Center, CEBM/CEBM@Brown, or the original OpenMeta[Analyst] authors and maintainers.
_Avoid_: No-endorsement note, casual disclaimer

**RC MetaStudio Project File**:
The maintained project-file format for RC MetaStudio, using the `.rcms` extension for saved analysis projects and sample projects.
_Avoid_: OMA file, `.oma` project file, legacy project file

**RC MetaStudio Project**:
The saved user work container opened and saved by RC MetaStudio, represented on disk as an RC MetaStudio Project File.
_Avoid_: Dataset file, OMA dataset, project dataset

**Retired OMA Compatibility**:
The removed ability to open, save, round-trip, test, document, or package `.oma` project files as a supported RC MetaStudio behavior.
_Avoid_: Backward compatibility, legacy read compatibility, OMA round trip

**RCMetaR API**:
The maintained callable R analysis interface exposed by the `RCMetaR` package, using `rcmetar.*` function names and current RC MetaStudio terminology.
_Avoid_: OpenMetaR API, `openmetar.*`, legacy R facade
