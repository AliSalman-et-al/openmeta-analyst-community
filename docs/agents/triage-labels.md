# Triage labels

Use this mapping when an agent skill names a canonical triage role.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified well enough for autonomous implementation. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The maintainers will not implement the issue. |
