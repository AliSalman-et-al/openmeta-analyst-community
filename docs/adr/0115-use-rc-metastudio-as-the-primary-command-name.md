# Use rc-metastudio as the Primary Command Name

The primary Python entry point and developer command should be `rc-metastudio`. The short `rcms` form may be added later as an optional alias, but the maintained documentation, CI, packaging scripts, and local developer workflow should use `rc-metastudio` as the canonical command.

Platform executables and app bundles should use product casing, such as `RCMetaStudio.exe` and `RCMetaStudio.app`.
