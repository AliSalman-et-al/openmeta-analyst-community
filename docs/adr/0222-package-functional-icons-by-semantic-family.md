# Package Functional Icons by Semantic Family

Functional Icon Masters will live under `images/icons/actions`, `images/icons/analyses`, and `images/icons/dataset-types`, with semantic filenames and matching stable Qt resource paths. After all canonical UI files, generated resource modules, tests, and packages use the Functional Icon Package, superseded functional PNGs and the historical `function_icon_set`, `toolbar-icons`, `startscreens`, and miscellaneous root placements will be removed; Brand Assets retain their existing paths.
