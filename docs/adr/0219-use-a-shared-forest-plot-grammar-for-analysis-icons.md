# Use a Shared Forest-Plot Grammar for Analysis Icons

Meta-analysis, cumulative meta-analysis, leave-one-out meta-analysis, subgroup meta-analysis, and meta-regression icons will retain a recognizable forest plot as their common anchor instead of replacing statistical meaning with abstract combination symbols. Estimate squares, confidence-interval lines, and a reference line form the base; cumulative and leave-one-out analysis share the same altered-row composition and differ through a green plus versus red minus operation badge, two visibly colored row groups distinguish subgroup analysis, and forest/scatter estimates with a fitted trend distinguish meta-regression. A shared pale Fluent supporting tile gives the fine plot geometry the same optical footprint as neighboring filled toolbar actions without thickening the statistical linework.
