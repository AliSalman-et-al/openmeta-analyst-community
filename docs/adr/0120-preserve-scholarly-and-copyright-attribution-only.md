# Preserve Scholarly and Copyright Attribution Only

Names associated with Brown University, Tufts Medical Center, CEBM/CEBM@Brown, and the original OpenMeta[Analyst] authors should remain only where they are part of scholarly/statistical references, original copyright or provenance notices, or `NOTICE.md` attribution. They should be removed from active support, contact, branding, callbacks, maintainer UI, packaging metadata, and current project documentation.

This preserves legitimate attribution without implying current affiliation, endorsement, sponsorship, support, or maintainership.
