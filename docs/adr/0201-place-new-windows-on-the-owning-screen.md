# Place New Windows on the Owning Screen

Parented Workflow, Transactional, and Transient Windows will open centered within the parent's current screen; first-use unparented Workspace Windows will open on the active application window's screen, while returning Workspace Windows use valid Remembered Workspace Placement. Moving between monitors must not recenter or snap a window, and screen-removal or DPI transitions may reflow and clamp geometry only as much as needed to keep the window reachable.
