# Keep an RC MetaStudio About and Legal Dialog

RC MetaStudio should keep an in-app About/Legal dialog after removing the bundled legacy help system. The dialog should show the RC MetaStudio name and version, maintainer identity, GPL-3.0-or-later license notice, no-warranty statement, and a concise derived-from-OpenMeta[Analyst] provenance note pointing to `NOTICE.md`.

Obsolete support links, Brown/CEBM callbacks, and original-maintainer contact details should be removed from the maintained UI.
