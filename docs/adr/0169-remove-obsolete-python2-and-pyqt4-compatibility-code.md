# Remove Obsolete Python 2 and PyQt4 Compatibility Code

RC MetaStudio should remove obsolete Python 2, PyQt4, fake compatibility shims, dead reference-runtime helpers, and generated bytecode that are not used by the maintained Python 3 and PyQt5 path. Historical ADRs may continue to explain why those files existed during modernization.

This keeps the RC MetaStudio source layout focused on the maintained runtime instead of preserving abandoned compatibility layers.
