# Lock RCMetaR Version to RC MetaStudio

While RCMetaR remains a private bundled implementation package, its version should be locked to the RC MetaStudio application version. A release such as RC MetaStudio `0.1.0` should bundle RCMetaR `0.1.0`.

Independent RCMetaR versioning should only be introduced if RCMetaR becomes a public package or gains a release cadence separate from the desktop application.
