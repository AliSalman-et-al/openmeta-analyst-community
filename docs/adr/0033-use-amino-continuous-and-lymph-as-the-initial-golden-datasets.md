# Use Amino Continuous and Lymph as the Initial Golden Datasets

The initial committed golden datasets will be `amino.oma`, `continuous.oma`, and `lymph.oma`. These files span the binary, continuous, and diagnostic analysis data families and remain useful for the modern golden analysis coverage.

Other sample projects such as `BCG.oma` and `meantime.oma` can be added after the first capture and comparison pipeline is stable.
