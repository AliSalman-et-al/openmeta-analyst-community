# Add a macOS-trusted release profile

RC MetaStudio will add a `macos-trusted` three-platform release profile in which the exact unsigned candidate bytes pass through a protected no-rebuild stage: both native macOS applications are Developer ID signed, notarized, stapled, and requalified, while Windows remains explicitly unsigned. The signing stage requires approval through a dedicated `macos-signing` GitHub Environment whose environment-scoped Apple credentials are unavailable before approval, publishes an immutable release candidate for ordinary promotion, retains `unsigned-community` as an explicit prerelease alternative, and never silently downgrades a failed trusted release; this activates the deferred macOS signing work from ADR 0260 without expanding scope to Windows Authenticode. Stable promotion requires the `macos-trusted` profile.
