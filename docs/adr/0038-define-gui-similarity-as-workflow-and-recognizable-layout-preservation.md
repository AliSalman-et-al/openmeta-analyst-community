# Define GUI Similarity as Workflow and Recognizable Layout Preservation

GUI similarity for the first Python 3 and Qt 5 milestone means preserving user workflows and recognizable layout, not pixel-perfect visual equivalence. Users should be able to perform the same core tasks through recognizable menus, dialogs, tables, controls, result summaries, and plot views, while Qt5-native spacing, font rendering, widget behavior, and minor layout differences are acceptable.

Screenshots can be used as review evidence, but they should not become pixel-diff gates for the first milestone.
