# Do not ship a pickle project converter

RC MetaStudio has not had a public pickle-era release, so the Qt6 release will not ship, document, or retain a pickle project converter. Before pickle support is removed, the repository's committed sample projects will be exported once into the Versioned Project Format and checked for semantic equivalence. The product, package, source tree, and release artifacts will then contain no pickle project reader, historical SIP or Qt-value decoder, or legacy-conversion entry point.
