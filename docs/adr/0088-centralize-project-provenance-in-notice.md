# Centralize Project Provenance in NOTICE.md

RC MetaStudio will keep full project attribution, licensing posture, maintainer identity, original-project provenance, and affiliation disclaimers in a top-level `NOTICE.md`. Source files should use compact copyright and license headers appropriate to Derived Maintained Files or New Maintained Files rather than repeating the full provenance statement in every module.

This makes legal and historical context easy to find while keeping rewritten source modules readable during the RC MetaStudio rebrand.
