# Block accessibility regressions in the Qt6 port

Accessibility regressions on the existing interaction surface block the first Qt6 release. Release evidence will cover complete keyboard access, visible focus, intentional tab order, accessible names and descriptions for non-text controls, readable fractional scaling, and dialogs that remain operable without a pointer. This gate preserves current capabilities and fixes port-created regressions; it does not authorize an unrelated interface redesign during the feature freeze.
