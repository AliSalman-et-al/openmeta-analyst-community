# Rename Product-Branded Internal Identifiers

RC MetaStudio will rename product-branded internal identifiers to the maintained identity, including Python bridge methods such as `load_OpenMetaR`, scripts and test names containing `openmetar`, package manifests, build variables, artifact names, and other runtime or tooling surfaces. Product-branded identifiers should become RC MetaStudio, RCMetaR, `rcmetar`, or `.rcms` equivalents as appropriate.

This does not rename generic evidence-synthesis concepts such as binary analysis, diagnostic data, forest plots, subgroup analysis, meta-regression, or confidence intervals. Those terms are domain language, not legacy product identity.
