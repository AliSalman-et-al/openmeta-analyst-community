# Cover Data Family Breadth Before Method Depth

The initial curated golden set should cover the major analysis data families before attempting exhaustive method coverage. It should include at least one binary analysis, one continuous analysis, one diagnostic analysis, and one cumulative or leave-one-out analysis, then expand method depth after the harness format and comparison reports are stable.

The existing legacy tests already provide candidate sample projects for this breadth-first set: `amino.oma` for binary analysis, `continuous.oma` for continuous analysis, and `lymph.oma` for diagnostic analysis.
