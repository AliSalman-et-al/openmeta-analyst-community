# Use RC MetaStudio Release and CI Artifact Names

RC MetaStudio should rename CI workflows, job labels, package names, executable names, app bundle names, archive names, bundle identifiers, release assets, and packaging documentation to the RC MetaStudio identity. Maintained release artifacts should not use OpenMeta[Analyst], OpenMetaAnalyst, OpenMetaR, OMA, or similar legacy names.

The identity migration should also remove `modern` as a maintained product, workflow, and artifact label. `Modern` may remain only in historical ADRs or narrowly historical discussion, not in current package names, CI lane names, artifact names, scripts, user documentation, or runtime identifiers.
