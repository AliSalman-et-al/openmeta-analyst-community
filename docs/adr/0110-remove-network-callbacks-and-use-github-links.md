# Remove Network Callbacks and Use GitHub Links

RC MetaStudio should remove dead Brown/CEBM callbacks, obsolete support links, update checks, bug-report endpoints, and original-maintainer contact callbacks during the identity migration. The maintained app should not make active network callbacks unless a future RC MetaStudio-owned service is explicitly introduced.

Static website, repository, or project links may point to `https://github.com/AliSalman-et-al/` for now. Brown University, Tufts Medical Center, CEBM/CEBM@Brown, and original OpenMeta[Analyst] support/contact links should not remain in active UI, docs, packaging metadata, or scripts.
