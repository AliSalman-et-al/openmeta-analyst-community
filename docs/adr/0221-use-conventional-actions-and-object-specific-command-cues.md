# Use Conventional Actions and Object-Specific Command Cues

Action Icons will preserve familiar cross-platform metaphors for navigation, open, save, undo, redo, copy, paste, calculator, add, and remove, while ambiguous main-window commands will combine the operation with its object. New Dataset, Edit Dataset, Import CSV, View Network, Add Covariate, Auto-Fit Columns, About/Legal, Quit, Save As, and Confidence Level therefore receive distinct table, document, network, doorway, or estimate cues instead of reusing a generic plus, folder, close mark, or text abbreviation.
