# Inventory Third-Party Assets and Components

The RC MetaStudio migration should include an inventory of bundled third-party assets and components, including UI assets, CSS/HTML remnants if any remain, icons/images, R package dependencies, and packaging resources. Compatible third-party license notices should be preserved separately from RC MetaStudio copyright and provenance.

This inventory should be completed before release packaging so bundled assets are not accidentally relabeled as RC MetaStudio-owned code.
