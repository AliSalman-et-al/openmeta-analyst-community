# Use GPLv3 License File and SPDX Headers

RC MetaStudio will include a top-level `LICENSE` containing the GNU General Public License version 3 text and will use SPDX-style source headers for maintained files. New Maintained Files should use `SPDX-License-Identifier: GPL-3.0-or-later` and `SPDX-FileCopyrightText: 2026 Ali Salman and RC MetaStudio contributors`; Derived Maintained Files should also preserve applicable original copyright/provenance lines where they remain accurate.

The full original-project and affiliation context belongs in `NOTICE.md`, not repeated in every source file.
