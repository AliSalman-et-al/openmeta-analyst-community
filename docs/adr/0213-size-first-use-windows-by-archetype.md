# Size First-Use Windows by Archetype

Without Remembered Workspace Placement, Main and Results open maximized, Edit Dataset and Network View target approximately 80 percent of the owning screen's available area, Workflow and Transactional Windows use their content-preferred size capped at 90 percent with declared overflow, and Transient Windows use their minimal content-preferred size. All calculations occur in Logical Layout Space and none become fixed stored pixel dimensions.
