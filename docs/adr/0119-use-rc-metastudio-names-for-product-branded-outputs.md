# Use RC MetaStudio Names for Product-Branded Outputs

Generated outputs, logs, artifact directories, default filenames, metadata keys, and manifests should use RC MetaStudio, RCMS, RCMetaR, `rcmetar`, and `.rcms` naming wherever product identity appears. Statistical domain labels such as forest plot, funnel plot, diagnostic analysis, subgroup analysis, and meta-regression should remain unchanged.

This keeps generated evidence and user-visible artifacts aligned with the rebrand without corrupting standard evidence-synthesis terminology.
