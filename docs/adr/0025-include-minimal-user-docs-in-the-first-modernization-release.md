# Include Minimal User Docs in the First Modernization Release

The first Python 3 and Qt 5 Windows release should include minimal user-facing documentation once a Windows distributable exists. The documentation should explain how to run the build, what analysis and project-file compatibility is intentionally preserved, and what modernization work remains out of scope for that release.

Developer migration notes can be written earlier, but the milestone should not be considered releasable without basic user documentation.
