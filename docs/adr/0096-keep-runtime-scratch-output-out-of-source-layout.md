# Keep Runtime Scratch Output Out of the Source Layout

RC MetaStudio should not keep runtime scratch directories, generated bytecode, test caches, analysis outputs, or packaging outputs inside importable source packages or committed repository paths. Runtime analysis artifacts should go to an app-managed user/cache directory or an explicit test temporary directory; build and packaging outputs should remain in ignored `build`, `dist`, or `artifacts` paths.

This removes legacy `r_tmp` assumptions from the source layout and keeps the repository tree focused on source, tests, documentation, package metadata, and reproducible fixtures.
