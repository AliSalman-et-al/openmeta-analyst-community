# Use a Professional Surface-Specific Functional Icon System

RC MetaStudio will use restrained, semi-flat professional color icons whose conventional desktop and statistical metaphors take priority over literal Windows 11 color-icon styling. Windows 11 contributes clarity, spacing, and geometric refinement, but bright layered illustration, decorative gradients, bubble-style badges, and pale supporting tiles are excluded. The portable SVG, semantic-family, accessible-label, and original-artwork decisions in ADRs 0216–0218 and 0222–0223 remain active. Existing dataset-type notation geometry and diagnostic matrix, Brand Assets, and splash artwork remain unchanged; dataset notation may use a single platform-neutral slate ink to retain contrast on both light and dark neutral surfaces.

Icon geometry and detail are optically tuned for each surface: 28 pixels in the main toolbar, 18 pixels in the Analysis menu, 16 pixels for repeated table decorations, and 20 pixels for outcome navigation. Analysis actions provide separate compact and standard masters through one multi-size `QIcon`; the compact form reduces plot rows and strengthens relative strokes rather than mechanically scaling the standard form. This surface-specific sizing is a Semantic Size Invariant and supersedes ADR-0211's style-derived icon extent for these named surfaces while leaving surrounding native Qt chrome under the platform style.

Analysis icons use transparent, high-contrast plot geometry. Meta-analysis uses a conventional forest plot and pooled diamond; cumulative and leave-one-out use identical base geometry with an integrated green plus versus red minus; subgroup uses a restrained violet grouping bracket; and meta-regression uses blue observations with a violet fitted trend. This supersedes ADR-0219's pale supporting tile and detached operation-badge treatment while preserving its shared statistical grammar.
