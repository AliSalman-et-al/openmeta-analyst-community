# Commit RCMS Sample Projects with a Manifest

RC MetaStudio should keep representative `.rcms` sample projects under `sample_projects` for desktop use, packaging smoke checks, and analysis behavior tests. The sample set should include a manifest documenting each sample project's analysis family, provenance, intended workflow coverage, and whether it is used by automated tests.

This preserves realistic project fixtures during the `.oma` retirement while making the sample corpus explicit and maintainable.
