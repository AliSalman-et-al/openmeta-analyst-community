# Use GPL-3.0-or-later SPDX for Maintained Files

Maintained RC MetaStudio source files should use `SPDX-License-Identifier: GPL-3.0-or-later` for the combined work while preserving applicable original copyright and provenance lines. The original OpenMeta[Analyst] GPL-2.0-or-later origin should remain documented in `NOTICE.md` and historical provenance, not as the active maintained file license identifier.

Third-party components with distinct compatible licenses should keep their own license notices and should not be relabeled as RC MetaStudio code.
