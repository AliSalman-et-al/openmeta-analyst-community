# Remove OpenMeta Branding from Generated Results

Generated result headers, plot metadata, captions, saved result files, report text, and analysis artifacts should not use OpenMeta/OpenMetaR/OpenMetaAnalyst branding when they identify the maintained software. They should use RC MetaStudio, RCMetaR, or neutral statistical terminology as appropriate.

Scholarly references, third-party package names, and statistical method labels should remain accurate.
