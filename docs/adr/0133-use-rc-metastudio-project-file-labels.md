# Use RC MetaStudio Project File Labels

File dialogs, packaging metadata, platform file-association metadata, tests, docs, and user-facing labels should describe project files as `RC MetaStudio Project (*.rcms)`. OpenMetaAnalyst dataset labels, OMA file labels, and `.oma` file associations should be removed from maintained active surfaces.

This makes the `.rcms` project-file identity visible and consistent wherever users open, save, or inspect project files.
