# Start an RC MetaStudio Changelog

RC MetaStudio should add a `CHANGELOG.md` starting with the first rebranded development release, such as `0.1.0`. The changelog should describe RC MetaStudio as an independently maintained modernization derived from OpenMeta[Analyst], summarize breaking identity changes such as `.rcms` project files, removal of `.oma` support, RCMetaR, removal of bundled legacy help, and point to `NOTICE.md` for provenance.

The changelog should focus on the maintained RC MetaStudio product rather than reconstructing the full release history of the original OpenMeta[Analyst] project.
