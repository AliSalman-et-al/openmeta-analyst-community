# Retain Network Meta-Analysis Code for Future Activation

RC MetaStudio should retain existing network meta-analysis code during the identity and layout migration because it may become an active feature in a later workstream. The code should be renamed, repathed, and cleaned of obsolete product identity with the rest of the codebase, but the migration should not introduce or expand network meta-analysis as an active supported feature.

Future activation should be handled as a separate feature workstream with its own verification and user documentation.
