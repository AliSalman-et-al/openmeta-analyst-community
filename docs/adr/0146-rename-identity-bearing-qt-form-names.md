# Rename Identity-Bearing Qt Form Names

The RC MetaStudio migration should rename Qt `.ui` filenames, generated class references, visible text, and object names when they carry OpenMeta[Analyst], OMA, `ma_`, `meta_`, or other product-era identity or unclear abbreviations. It should not churn every internal widget object name purely for style.

Widget object names can be modernized opportunistically when editing the relevant form, with priority on visible UI text and maintainability-relevant identifiers.
