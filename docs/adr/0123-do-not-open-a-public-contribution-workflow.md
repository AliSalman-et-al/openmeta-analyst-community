# Do Not Open a Public Contribution Workflow

RC MetaStudio is not accepting public contributions at this time. The repository should not present a normal public contribution workflow, governance model, or contributor onboarding path until the maintainer explicitly decides to accept outside contributions.

If a contribution policy file is added, it should be a short maintainer policy stating that unsolicited public contributions are not currently accepted, rather than a standard `CONTRIBUTING.md` that invites pull requests.
