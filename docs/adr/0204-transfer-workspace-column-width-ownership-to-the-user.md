# Transfer Workspace Column-Width Ownership to the User

Workspace tables will auto-fit columns when a schema is first shown and then transfer Column-Width Ownership to the user, preserving adjusted widths across later data and model changes while assigning sensible widths only to newly introduced columns. Users will have an explicit auto-fit action when they want recomputation. Compact Transactional tables may continue fitting to content, but excess table dimensions must overflow within the table rather than enlarge the root window.
