# Use Filled Fluent Color Functional Icons

Functional Icons will use original filled geometric shapes, bright layered color, soft corners, restrained gradients, minimal outlines, and strong small-size silhouettes following the supplied Windows 11 color-icon references. This supersedes ADR-0215's monoline Action Icon treatment while retaining conventional action metaphors, the shared statistical grammars, the semantic color vocabulary, and the prohibition on copied Microsoft artwork.
