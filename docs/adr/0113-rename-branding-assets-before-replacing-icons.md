# Rename Branding Assets Before Replacing Icons

The RC MetaStudio identity migration should rename branding asset filenames, package paths, references, and metadata to RC MetaStudio conventions, but full visual replacement of icons and branding artwork is deferred to a later branding workstream. Functional non-branded icons may remain temporarily if their licensing is compatible and they do not expose old OpenMeta[Analyst], Brown, Tufts, or CEBM identity in the UI.

Visible product text should still be updated during the identity migration even when the underlying icon artwork is only renamed.
