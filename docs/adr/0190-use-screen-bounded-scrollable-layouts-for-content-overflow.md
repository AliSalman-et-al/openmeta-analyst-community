# Use Screen-Bounded Scrollable Layouts for Content Overflow

When a window's preferred content cannot fit within the usable screen, RC MetaStudio will cap the top-level window to the available screen area and expose overflow through a scrollable content region. Native font and control sizes remain intact; the application will not shrink typography, compress controls below usable size, or allow required content to become unreachable merely to keep the whole layout visible at once.
