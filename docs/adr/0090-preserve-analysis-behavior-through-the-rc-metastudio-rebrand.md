# Preserve Analysis Behavior Through the RC MetaStudio Rebrand

The RC MetaStudio rebrand deliberately retires OpenMeta[Analyst] product, file, package, and API compatibility, but it does not authorize silent changes to statistical Analysis Behavior. Golden and behavior tests should be rebased onto RC MetaStudio Project Files, `RCMetaR`, and `rcmetar.*` terminology while continuing to protect user-relevant analysis inputs, model choices, numerical outputs, summaries, and generated artifacts unless a reviewed Statistical Modernization Drift or Compatibility Exception records the change.

This separates identity cleanup from evidence-synthesis correctness: RC MetaStudio no longer presents itself as OpenMeta[Analyst]-compatible software, but its maintained analysis behavior still requires explicit regression evidence.
