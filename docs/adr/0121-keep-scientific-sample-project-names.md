# Keep Scientific Sample Project Names

RC MetaStudio should keep scientifically meaningful sample project names such as `amino`, `continuous`, `lymph`, and `BCG` while changing their supported file extension to `.rcms`. Sample names should only change when they contain OpenMeta[Analyst], OMA, Brown, Tufts, CEBM, or obsolete support/branding identity.

The sample-project manifest should document each sample's provenance and workflow coverage.
