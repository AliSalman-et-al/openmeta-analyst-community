# Keep Only a Functional Rebranded Welcome Screen

RC MetaStudio may keep a welcome or start screen if it provides current functional actions such as New Project, Open Project, Recent Projects, and static GitHub/Issues links. OpenMeta[Analyst] website/help/support text, Brown/CEBM links, and legacy branding should be removed.

If the existing welcome page is mostly abandoned-project content, it should be simplified aggressively during the identity migration.
