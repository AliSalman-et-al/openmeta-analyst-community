# Rename RCMetaR Product-Branded R Files and Topics

RCMetaR source filenames, roxygen topic names, aliases, tests, and internal docs should use `rcmetar-*` naming wherever they describe the package facade or product identity. `openmetar-*` names should not remain in maintained active R package surfaces.

Statistical domain filenames and topics, such as binary methods, diagnostic methods, forest plots, or meta-regression, should keep clear domain names rather than being renamed purely for branding.
