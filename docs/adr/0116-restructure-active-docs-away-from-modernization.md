# Restructure Active Docs Away from Modernization

Active RC MetaStudio documentation should move out of the `docs/modernization` organizing frame into current project areas such as `docs/architecture`, `docs/verification`, `docs/packaging`, `docs/development`, and `docs/provenance`. Current ADRs should remain under `docs/adr` as decision history.

This removes modernization-era framing from maintained documentation while keeping verification, packaging, provenance, and architecture evidence discoverable.
