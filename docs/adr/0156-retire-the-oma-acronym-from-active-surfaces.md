# Retire the OMA Acronym from Active Surfaces

RC MetaStudio should retire `OMA` and `oma` as active product acronyms in code, docs, environment variables, tests, package metadata, settings, generated outputs, and artifact names. Use `RCMS` for compact product-scoped identifiers.

The old acronym should remain only in historical ADRs, provenance notes, scholarly context where accurate, or explicit discussion of removed `.oma` files and Retired OMA Compatibility.
