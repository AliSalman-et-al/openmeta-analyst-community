# Use Evidence-Based Verification Lane Names

RC MetaStudio should replace maintained `modern-*` workflow, script, test, and documentation labels with evidence-based verification lane names. Active lanes should use names such as `smoke`, `fast`, `package`, `r-stack`, `analysis-baseline`, `analysis-regression`, and `verification` rather than `modern-smoke`, `modern-fast`, `modern-package`, `modern-r-stack`, or `modern-golden`.

This removes the old modern-versus-legacy framing from the maintained project while preserving historical modernization wording only where it remains part of ADR history.
