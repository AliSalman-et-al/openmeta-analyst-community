# Remove Legacy Framing from Active Surfaces

RC MetaStudio active code, tests, scripts, manifests, user documentation, and developer documentation should avoid generic `legacy` framing. Use precise project terms instead: Original OpenMeta[Analyst] Project for provenance, Retired Reference Implementation for the old runtime when historical analysis evidence requires it, `.oma` files or Retired OMA Compatibility for the removed file-format support, and RC MetaStudio for the maintained product.

Historical ADRs may keep legacy wording where it records the modernization period, but active surfaces should not describe RC MetaStudio as a transitional fork forever.
