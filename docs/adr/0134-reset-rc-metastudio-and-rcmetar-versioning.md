# Reset RC MetaStudio and RCMetaR Versioning

The first rebranded RC MetaStudio development release should use a fresh pre-1.0 version such as `0.1.0` instead of continuing OpenMeta[Analyst] or modernization-era versioning. The bundled private RCMetaR package should also reset to the corresponding RC MetaStudio-era version rather than preserving OpenMetaR tarball/version identity.

The project can promote toward `1.0.0` after the rebrand, `.rcms` project-file identity, RCMetaR package/API rename, packaging, and verification lanes are stable.
