# Launch the Real MetaForm Shell as the First Full Port Slice

The first Full Legacy App Port slice should start the Reference Implementation entry path far enough to create the real `MetaForm` shell under Python 3.11 and PyQt5. Lower-level model, dialog, and analysis fixes should then land against that integration target, because only the real launcher and `MetaForm` path exposes launcher, settings, generated UI, signal, and main-window incompatibilities.
