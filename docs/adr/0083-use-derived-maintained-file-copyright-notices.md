# Use Derived Maintained File Copyright Notices

Because the maintained codebase has broadly rewritten or edited the original OpenMeta[Analyst] files, RC MetaStudio should treat original-source descendants as Derived Maintained Files rather than trying to preserve an "untouched legacy file" category. Derived Maintained Files should preserve applicable original copyright and provenance notices where accurate, add the RC MetaStudio Modification Notice for Ali Salman and RC MetaStudio contributors, and distribute the combined maintained work under GPL-3.0-or-later where permitted by the original GPL-2.0-or-later grant; New Maintained Files should use only the RC MetaStudio copyright and GPL-3.0-or-later notice.
