# Distinguish Project Files from Analysis Datasets

RC MetaStudio should use Project language for saved `.rcms` containers and Dataset language for the study data inside a project. Menus, file dialogs, recent-file labels, sample-project docs, and packaging smoke checks should say New Project, Open Project, Save Project, and RC MetaStudio Project.

Analysis and data-table UI may still use Dataset when referring to the evidence data being analyzed.
