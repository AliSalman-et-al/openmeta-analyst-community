# Compose Dataset-Type Icons from Group Count and Measure

Dataset-type icons will use one teal data group for one-arm data and two contrasting groups for multi-arm data, then add a consistent measure cue: a segmented whole for proportions, an estimate and interval for means or generic effects, a fitted slope for a regression coefficient, a measured gap for standardized mean difference, and a 2-by-2 test-by-condition matrix for diagnostic data. This exposes the highest-level choice before the detailed measure while keeping all eight options within one learned visual family.
