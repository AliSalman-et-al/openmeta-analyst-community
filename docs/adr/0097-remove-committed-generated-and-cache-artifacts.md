# Remove Committed Generated and Cache Artifacts

The RC MetaStudio layout migration should delete committed generated bytecode, cache directories, stale build products, and runtime leftovers such as `.pyc`, `__pycache__`, `.pytest_cache`, `.ruff_cache`, legacy `r_tmp` output, and obsolete packaging artifacts. `.gitignore` should be tightened so these files do not return.

This cleanup is part of the mechanical repository reorganization because it removes non-source noise without changing maintained Analysis Behavior or module interfaces.
