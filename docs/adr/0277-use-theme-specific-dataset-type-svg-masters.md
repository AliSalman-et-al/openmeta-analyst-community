# Use Theme-Specific Dataset-Type SVG Masters

Dataset-type choices use checked-in light- and dark-palette SVG masters and switch resource paths when the button palette changes. They must not recolor a rasterized icon with painter composition: that softens notation edges and flattens the Diagnostic Data matrix's internal tones and marks.

This is a narrow exception to ADR 0217's theme-neutral-master decision. Other Functional Icons remain theme-neutral unless a separately verified rendering seam requires variants.
