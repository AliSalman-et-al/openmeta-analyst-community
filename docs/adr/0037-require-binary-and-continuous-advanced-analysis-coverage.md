# Require Binary and Continuous Advanced Analysis Coverage

Before the first Python 3 and Qt 5 milestone is releasable, meta-regression and subgroup analysis compatibility must include at least binary and continuous data-family coverage. Diagnostic meta-regression and subgroup coverage should be added if feasible, but it is not the minimum release gate for the first milestone.

This preserves important advanced analysis workflows without requiring the full cross-product of data families and methods before the core port can ship.
