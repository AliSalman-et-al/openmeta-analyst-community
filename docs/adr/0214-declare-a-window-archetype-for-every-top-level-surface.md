# Declare a Window Archetype for Every Top-Level Surface

The authoritative inventory classifies Main, Results, Edit Dataset, and Network View as Workspace Windows; every Main Wizard path as a Workflow Window; analysis, data-entry, plot-editing, selection, naming, confidence, back-calculation, About/Legal, and other focused one-action surfaces as Transactional Dialogs; and splash or progress surfaces as Transient Windows. Every future top-level surface must explicitly declare one of these Window Archetypes so its sizing, placement, overflow, and Geometry Ownership are governed intentionally.
