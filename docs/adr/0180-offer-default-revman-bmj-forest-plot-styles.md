# Offer Default, RevMan, and BMJ Forest-Plot Styles

Status: accepted — post-cutover Post-Port Refactor; builds on ADR 0179.

The Edit Forest Plot dialog should expose a Forest Plot Style dropdown offering three styles — **Default** (the plain `metafor::forest()` layout), **RevMan** (Cochrane Review Manager house layout), and **BMJ** (BMJ house layout) — each rendered as a full faithful layout template on the metafor renderer from ADR 0179, not as a cosmetic recolor. The metafor gallery reproductions of RevMan and BMJ are bespoke per-dataset scripts (hardcoded `xlim`/`ilab.xpos`/`textpos`, post-hoc `text()`/`segments()`/`points()`, dataset-specific columns and brand colors); adopting them means generalizing each into a parameterized template that computes its coordinates and column set from the analysis data.

`fp_style` is a per-plot forest-plot param stored alongside the existing `fp_*` params in the render bundle. Its default is **Default**, applied both to new analyses and to existing `.rcms`/`.params` that predate the param — since the custom engine is retired, pre-existing plots re-render as Default metafor. Style is selectable **only in the Edit Forest Plot dialog**: the first auto-generated render (from the ma_specs forest-plot options) is always Default, and the user restyles post-hoc; the choice persists so save-as and regenerate honor it. RevMan and BMJ are offered for **all data families, including diagnostic single plots**; because RevMan/BMJ define no authentic diagnostic layout, the diagnostic templates are designed in-house (count columns drawn from TP/FN/TN/FP or the metric numerator/denominator, plus weight and effect/CI). Diagnostic side-by-side plots remain Default-only until the ADR 0179 side-by-side phase lands; extending RevMan/BMJ to twin-panel is a deferred decision.

RevMan is implemented **without** risk-of-bias columns, symbols, or legend — risk of bias is explicitly not a feature we are adding. The dialog uses **per-style control panels**: Default exposes metafor-idiomatic column toggles (show/hide the raw-count `ilab` columns, their headers, and the annotation column) rather than the literal legacy col1–4 model, because Default is a metafor-idiomatic redesign (see ADR 0182), not a reproduction of the legacy column set; RevMan and BMJ own their columns and expose only their relevant knobs. A **universal appearance group** applies to every style: a single accent-color picker driving study points, CI lines, and the summary diamond (per-style default presets — Default metafor, RevMan black, BMJ purple `#6b58a6`), plus weight-scaled point sizing (`psize`) with a size-multiplier control. Brand fonts are approximated with a clean default family; exact house fonts (e.g. BMJ InterFace) are not chased, so plots render consistently across the bundled R Stack on all platforms.

## Consequences

- Depends on ADR 0179; the RevMan/BMJ templates are `forest()` + `addpoly()` + annotation compositions keyed to the bundled `res`, dispatched on `fp_style`.
- Full faithful templates carry per-data-family column sets: binary two-group events/total, continuous mean/SD/N, and in-house diagnostic count columns — each with weight %, effect/CI, subtotals/subgroup diamonds, and heterogeneity + test-for-overall-effect blocks where the style shows them.
- The Edit Forest Plot `.ui`/generated form gains a style dropdown, a universal appearance group, and per-style control panels; the generic col1–4 controls become Default-only.
- Verification per ADR 0179: headless render-smoke covers each style × data-family; manual GUI Verification Evidence signs off the RevMan/BMJ look.
- No new dependency and no Analysis Behavior change; not gated by ADR 0175.
