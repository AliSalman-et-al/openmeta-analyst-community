# Replace the Custom Forest-Plot Engine with a metafor Renderer

Amendment: ADR 0186 supersedes this ADR's side-by-side phase and render-bundle
flag. Maintained diagnostic metrics now use standalone forest artifacts; the
persisted Forest Render Bundle no longer carries a side-by-side field.

Status: accepted — post-cutover Post-Port Refactor.

RC MetaStudio should retire its custom grid-graphics forest-plot engine (`forest.plot`, `draw.forest.plot`, `draw.data.col`, and the `create.plot.data.*` render pipeline in `r/RCMetaR/R/plotting.R`) and render forest plots with `metafor::forest()` instead. `metafor` is already a first-class dependency (`DESCRIPTION`, `NAMESPACE` `import(metafor)`): every `rma.uni`/`rma.mh`/`rma.peto` fit that produces the `res` object already comes from it, and base `graphics` — which `forest()` uses — is already imported. So this reuses existing dependencies rather than adding a statistical capability. The custom engine hand-rolls square/CI/diamond drawing, CI-truncation arrows, device sizing, and heterogeneity annotation that `forest()` + `addpoly()` provide natively and more legibly.

This is a deliberate departure from the legacy Plot Similarity oracle, taken because Release Cutover has landed (commit `8110fa9`), the Reference Implementation is retired as the oracle, and the binding regression baseline is now the Modern Behavior Baseline. ADR 0175 (freeze statistical feature scope during migration) governed only the migration window and does not gate post-cutover presentation work; because rendering changes reuse `metafor` and add no analysis method, ADR 0175's dependency and scope constraints are not implicated.

Analysis Behavior is unchanged: the same `rma` computations feed the renderer, so numeric and text goldens stay valid. The existing golden suite compares plots by artifact **presence** plus numeric/text drift (`test_compare_bundle_requires_expected_plot_artifacts`, `NUMERIC_DRIFT`, `TEXT_ARTIFACT_DRIFT`), not pixels, so the renderer swap does not trip image comparison. The persisted render bundle (`.plotdata`) is redefined to be a self-contained render spec carrying the `rma` result (or, for single-study and Entered Diagnostic Effect Estimate cases that build a plain list, the normalized effect/CI/`slab` vectors), `params`, data-type, side-by-side flag, and `fp_style`. Because `res` does not carry the raw 2x2 counts or mean/SD/N, and save-as reloads only the bundle, the bundle also carries a **precomputed ilab spec** for the chosen style — the ilab column matrix, column headers, study weights, effect/CI values, and subgroup structure — so the renderer can redraw without reloading `om.data`. This makes the pipeline a builder → renderer split: `rcmetar.regenerate.plot.data` is the builder that turns `(om.data, res, params, fp_style)` into the spec, and `rcmetar.draw.forest.plot` is a pure placer over `metafor::forest()`. This keeps every Python round-trip entry point stable (`regenerate_plot_data`, `update_plot_params`, `generate_forest_plot`, `save_image_as` reloading `.plotdata`) while the R-side renderer calls `forest(res, ...)` directly. Column sets, device sizing, and module layout for the renderer are specified in ADR 0182.

## Consequences

- Execution is **phased**. Phase 1 replaces single (binary/continuous/diagnostic), Subgroup Analysis, cumulative, and leave-one-out plots — all native `metafor` (`forest`, `addpoly`, `cumul`, `leave1out`). The diagnostic side-by-side plots (`two.forest.plots`, Sens|Spec and PLR|NLR) keep the legacy renderer until a final phase builds a `layout()`/`par(mfrow)` twin-panel composition, since `forest()` is single-panel with no native equivalent.
- `grid` becomes removable from `NAMESPACE`/`DESCRIPTION` only after the side-by-side phase retires the last custom-engine caller.
- Verification: existing presence+numeric goldens are retained; new headless R render-smoke tests assert each style × data-family produces a non-empty PNG of sane dimensions with expected text (study labels, summary row, weight column); manual GUI Verification Evidence captures visual sign-off. No perceptual/pixel-diff baselines, consistent with the documented "no pixel-perfect plot diff" stance.
- Plot goldens are re-blessed against the Modern Behavior Baseline; the renderer change is recorded as an intentional Plot Similarity departure, not a Compatibility Exception.
- Out of scope and untouched: the meta-regression scatter (`meta.regression.plot`), SROC/HSROC plots, and all `rma` computations.
- Recommended module layout: `r/RCMetaR/R/forest_metafor.R` houses the Metafor-backed entrypoint, `fp_style` dispatcher, support checks, and bundle builders behind the stable `rcmetar.draw.forest.plot` entry point; concrete styles live in `forest_style_*.R` modules.
- Enables ADR 0180 (selectable forest-plot styles), which builds the RevMan and BMJ templates on this renderer.
