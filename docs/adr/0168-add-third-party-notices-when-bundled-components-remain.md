# Add Third-Party Notices When Bundled Components Remain

RC MetaStudio should add a `THIRD_PARTY_NOTICES.md` file if the third-party inventory finds bundled third-party assets or components beyond normal package dependencies. `NOTICE.md` should remain focused on RC MetaStudio and OpenMeta[Analyst] provenance; `THIRD_PARTY_NOTICES.md` should record bundled third-party materials and their licenses.

This file should be created during the third-party inventory phase rather than as an empty placeholder.
