# Use Path-Based Mathematical Notation for Dataset-Type Icons

Dataset-type icons will use the notation already familiar to meta-analysis users: `x/N` for one-arm proportions, `μ` for one-arm means, `β` for regression coefficients, `(θ, SE)` for generic effects, paired subscripted expressions for two-arm data, and `g` for standardized mean difference. Diagnostic data retains a conventional 2-by-2 matrix. Simple symbols use square masters, while wide generic and paired expressions use aspect-ratio-matched SVG canvases and UI slots so their notation is not compressed or optically undersized. Matplotlib MathText converts every glyph to an SVG path at generation time, so the packaged icons are monochrome, portable, and independent of runtime fonts, TeX, Matplotlib, or the operating system.
