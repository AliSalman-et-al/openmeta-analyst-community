# Use a Specific Repository URL When Available

RC MetaStudio metadata should use a specific repository URL once the final repository name is confirmed, such as a future `https://github.com/AliSalman-et-al/rc-metastudio` URL. Until then, static UI and documentation links may use the GitHub namespace `https://github.com/AliSalman-et-al/` as a temporary placeholder.

The migration plan should include updating package metadata, README links, About/Legal links, issue links, and packaging metadata to the specific repository URL when it exists.
