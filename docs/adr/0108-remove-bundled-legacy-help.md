# Remove Bundled Legacy Help

RC MetaStudio should remove the bundled OpenMeta[Analyst] help documentation and remove in-app access points that open it during the identity migration. New RC MetaStudio user documentation should be created in a later documentation workstream rather than renaming or partially editing the old help pages.

This avoids shipping stale Brown/CEBM-era support links, obsolete screenshots, and product guidance that no longer matches the RC MetaStudio identity or maintained file/API surface.
