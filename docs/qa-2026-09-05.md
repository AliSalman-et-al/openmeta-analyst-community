# Desktop QA for 0.4.0

Tested on Windows on 5 September 2026. Exploratory QA ended at the maintainer's request after the fixes below were checked.

## Bugs fixed

- Normal packaged startup imported the R bridge before configuring bundled R. The shared startup path now configures R first. Package qualification clears inherited R settings so developer configuration cannot conceal a broken bundle.
- Opening a project from an untouched startup wizard prompted to save. Composition now establishes the initial clean workspace for interactive and automated launches alike.
- Binary, continuous, and diagnostic projects opened with blank calculated-effect columns. Loading and changing the active selection now reconstruct transient previews without changing persisted inclusion choices or entered effects.
- CSV rows with complete raw data and blank calculated-effect columns arrived excluded. Import no longer changes inclusion in response to those blank calculated fields.

## Observed workflows

- Normal packaged launch reached the startup wizard.
- Binary random-effects analysis produced OR 0.77, 95% CI 0.48–1.22, p = 0.267, and a forest plot.
- Publication Bias displayed eligibility for 17 of 19 studies, asymmetry-test results, and a funnel plot.
- Negative counts were rejected without changing the original data. A valid edit updated its effect preview; undo restored the original data and clean state.
- Continuous random-effects analysis displayed its summary and forest plot.
- Reitsma analysis completed for 17 diagnostic studies and displayed summary sensitivity 65.76%, specificity 80.97%, and an SROC plot.
- Save As, changing confidence to 90%, saving, and reopening preserved the diagnostic data and confidence setting.
- A three-study synthetic CSV imported its names, years, and counts. After manually including the rows in the affected build, analysis and saving succeeded.
- Saved workspaces closed without a save prompt.

The final source application was then launched with real R. Opening `amino.rcms` filled OR and confidence bounds immediately without a save prompt. Its first row showed 0.57, 0.17, and 1.92, matching the forest plot.

## Verification limits

The packaged run and extraction qualification tested commit `350d9c1`. Its ZIP SHA-256 was `6071b82b83179a33346e984615d2e62ad2e29f88c628280b8675ddaff07a7e91`. This is not evidence for a rebuilt 0.4.0 release package.

The final fixes passed 134 affected launch, editing, and CSV tests, targeted lint checks, and type checking with generated Qt modules available. Regression coverage includes all three raw-data families, incomplete rows, entered-only effects, saved inclusion choices, and clean startup followed by a real edit.

GitHub Actions subsequently built and qualified the Windows 0.4.0 package at `691b528` and passed the full Windows R-stack evidence lane in run `33947323317`.

The CI follow-up exposed stale developer scripts: removed command names, old undo operations, and pre-versioned analysis fixtures. These callers were migrated instead of restoring compatibility paths. Shell checks that only printed success were removed from production and replaced with external checks that exercise startup and failure cleanup. `scripts/check_script_contracts.py` checks script and workflow command names against the current application entry points.

Apple silicon package qualification and final release-artifact qualification remain separate release checks. This pass does not claim exhaustive testing of every analysis option or platform.
