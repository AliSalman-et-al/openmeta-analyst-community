Starting RCMetaStudio

To start RCMetaStudio, open the folder where you extracted the RCMetaStudio program files and double-click the file

This opens the Welcome to OpenMeta dialog, as shown below.

In the dialog, you can create a new dataset or open an existing dataset. As an example, open the sample dataset amino.rcms by the following steps:

  1. Click the open button.
  2. In the Open File dialog, double-click the sample_data directory.
  3. Select the file amino.rcms.
  4. Click Open.

This opens the main RCMetaStudio window, as shown below.

The next section describes the RCMetaStudio window in detail.

Tip: You can create a shortcut to RCMetaStudio by dragging the RCMetaStudio.exe icon onto the desktop.
