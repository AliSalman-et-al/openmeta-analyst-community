Creating a New Dataset

To create a new dataset in the main RCMetaStudio window, do the following steps.

  1. Select new dataset fon the Dataset menu.

  2. In the New Dataset dialog, type the name of the dataset:

  3. Select the type of data you are working with, which can be of the following types:
    • Binary or continuous
    • Diagnostic

    In this example, the data type is binary. See Datasets for description of the data types available in RCMetaStudio.

  4. Select create new. This opens the add new outcome dialog shown below.

  5. In the dialog, type a name for the outcome of the treatment and select the type of outcome, depending on the type of data you are analyzing.
  6. Click OK.

This opens the RCMetaStudio window. For binary data, the window appears as shown below.

The next section shows how to enter data in the dataset.

Note: You can also create a new dataset in the Welcome to RCMetaStudio dialog by clicking the create new button and following steps similar the procedure above.
